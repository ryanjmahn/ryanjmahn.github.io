## jekyll vs vanilla — vanilla, with one small node script

Pages would run Jekyll here (there's no `.nojekyll`), but Jekyll won't install against this Mac's system Ruby (2.6). Shipping layouts I can't build and look at locally is a bad risk for an application site. So pages stay plain static HTML, the way the repo already works, plus one dependency-free script:

- `tools/projects.json` holds the facts: sheet, title, dates, role, team, status, links, numbers, category. Also `drafts` (hidden, never rendered).
- `node tools/build.js` writes the shared chrome of every `work/<slug>/index.html`: head, nav, title block, figure frame, receipts, prev/next. It also writes the log on the home page and `sitemap.xml`, then lists every remaining `RYAN-WRITES` slot.
- **Your writing lives in each case study between `<!-- RYAN:BEGIN -->` and `<!-- RYAN:END -->`.** The build never touches what's between those markers, so you edit the page in place, rerun the build, and nothing you wrote is lost.
- `assets/js/site.js` also does a `console.warn` in the browser while any `.todo` slot remains.

## fonts

- display: **Instrument Serif** (regular + italic, self-hosted, already in the repo). No bold exists, and `font-synthesis: none` stops the browser faking one.
- body: **Instrument Sans** (self-hosted, already in the repo). It sits well beside the serif, so no Inter/Geist.
- mono: **JetBrains Mono** 400, self-hosted. It's a Google Fonts subset covering latin plus the arrows (→ ← ↗) and `·`/`§`/`Å`. The stock latin subset lacks →.
- fallbacks: `Georgia, serif` / `system-ui, sans-serif` / `ui-monospace, Menlo, monospace`.
- self-hosted rather than linked from Google Fonts: fewer origins, better Lighthouse, same files.

## second pass — carving

The truss figure (DWG-002) moved off the home page to `/work/openwm/`, where it's the OpenWM demo (this overrides the brief's "must remain on the homepage", per your request). The home page's figure is now pl. 1, Rodin's *Pygmalion and Galatea* (Met Open Access, CC0). It starts as a rough block of stone and is carved away as the page scrolls (`assets/js/carve.js`): the block goes from the outside in, then the figure's surface resolves. Dragging across it carves by hand. On a phone the statue sits between the intro and the log and carves as it passes. Under reduced motion it's shown finished.
