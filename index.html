Benchmark Design in Cryptic Pocket Prediction

sole author · w/ prof. se-jin hwang · CJSJ semi-finalist, under review

solo-benchmarked three software tools on detecting the switch-ii cryptic pocket in kras g12d, using a 24-conformer normal-mode ladder built from the crystal structure. the tool built for cryptic pockets placed last. extended to 218 targets to ask when a prediction is worth believing.

0.95 MCC for the simplest tool vs 0.12 for the specialist · scaled to 218 proteins · a trust rule right 75% of the time against 37% overall
